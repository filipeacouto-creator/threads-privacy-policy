Política de Privacidade

Última atualização: 28 de outubro de 2026

Responsável

Esta integração é operada por Filipe Couto Desenvolvimento de Software Ltda.

Finalidade

O aplicativo é uma integração pessoal e local com a API do Threads. Ele é usado exclusivamente para consultar e administrar conteúdos vinculados à conta Threads autorizada pelo titular.

Dados tratados

Quando autorizado pelo titular, o aplicativo pode acessar dados disponibilizados pela API do Threads, como identificador da conta, nome de usuário, informações de perfil e conteúdos públicos solicitados pelo próprio titular.

Armazenamento e compartilhamento

Os dados são tratados localmente no equipamento do titular. O token de acesso é armazenado somente no armazenamento seguro local do sistema. Não vendemos, alugamos nem compartilhamos dados pessoais com terceiros.

Retenção e exclusão

Os dados locais podem ser removidos pelo titular a qualquer momento. Para solicitar esclarecimentos ou exclusão de informações eventualmente armazenadas, entre em contato pelo e-mail abaixo.

Segurança

São adotadas medidas razoáveis para proteger as credenciais e os dados tratados localmente. Nenhuma transmissão ou armazenamento eletrônico pode ser garantido como absolutamente seguro.

Alterações desta política

Esta política poderá ser atualizada para refletir alterações na integração ou em requisitos aplicáveis. A versão vigente ficará disponível nesta página.
